# Conversation

Zona central del detalle de lead: un composer arriba que cambia según la etapa y el timeline de actividad debajo.

- El composer unifica las acciones de IA: sin contacto → "Apertura sugerida"; con respuesta → "Pegá lo que respondió" + Analizar; en "Ahora no" con fecha cumplida → "Seguimiento".
- El texto generado siempre es editable antes de enviar. Botón primario = enviar; regenerar es ghost.
- Eventos entrantes (respuestas del prospecto) con punto `signal`; propios y del sistema con `smoke-4`.
- Fechas y horas en mono, alineadas a la derecha.
