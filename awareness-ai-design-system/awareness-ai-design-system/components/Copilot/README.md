# Copilot

Panel derecho del detalle de lead que concentra todo lo que la IA sabe del negocio: score de interés, dolores, objeciones, señales de compra y enriquecimiento.

- Score en mono y `signal-text`, con una línea de por qué cambió.
- Dolores, objeciones y señales como chips; el hover muestra la evidencia (cita del mensaje).
- Mientras la IA procesa se usa el shimmer de humo (`aw-smoke`), nunca spinners.
- Estado vacío en una línea: "Sin análisis todavía. Enriquecé el lead para empezar." + botón.
