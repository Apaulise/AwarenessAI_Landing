# Tabs

Dos formas de alternar vistas: segmented control para modos de visualización y tabs subrayados para secciones de contenido.

- Segmented (`aw-seg`): período del dashboard, Mes/Semana/Lista en Agenda. Activo en `raised`.
- Tabs (`aw-tabs`): modos de "Generar lista" (Google Maps / CSV), pestañas del detalle. Activo con subrayado de 2px en `signal`.
