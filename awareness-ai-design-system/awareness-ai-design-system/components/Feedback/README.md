# Feedback

Estados vacíos y toasts: siempre dicen qué pasó y qué hacer a continuación.

- Estado vacío: una línea de contexto + una acción, entre líneas punteadas `line-strong`. Nunca una card grande vacía.
- Toast: `raised` + `shadow-pop`, punto `success` o `danger`, texto con datos concretos (cantidad, costo). Desaparece a los 4s; los de error quedan hasta cerrarlos.
