# StatusBadge

Badge de etapa del pipeline: punto de color + etiqueta, agrupado por temperatura del lead.

- Variantes: default (frío), `--curso`, `--caliente`, `--ganado`, `--pausa`, `--salida`. El mapeo completo está en la tabla "Estados del pipeline" del README.
- El color solo refuerza; la etiqueta siempre está escrita.
- En el header del detalle de lead, el badge funciona como selector para cambiar de etapa.
